# USA Concrete Jobs — Programmatic SEO Site

## Overview
A complete programmatic SEO site targeting concrete cutting, waterproofing, and concrete finishing searches across Texas, Florida, California, Arizona, and Colorado. Built with Astro + Cloudflare Pages for zero hosting cost and maximum performance.

## Site Structure
- **Homepage** — multi-state targeting
- **5 state pages** — e.g., `/states/texas/`
- **County pages** — e.g., `/states/texas/dallas-county/`
- **City pages** — e.g., `/states/texas/dallas-county/dallas/`
- **Service pages** — Concrete Cutting, Waterproofing, Concrete Finishing, Core Drilling
- **Cost guide** — `/cost/`
- **About page** — `/about/`
- **Regulations page** — `/regulations/`

## States Covered
Texas, Florida, California, Arizona, Colorado

## SEO Features
- Unique title, meta description, H1, and canonical URL per page
- Organization + WebSite + HomeAndConstructionBusiness schema
- Speakable schema for AI engine optimization
- Localized cost ranges and content by state

## Deployment (Cloudflare Pages)
1. Push this repo to GitHub
2. Connect to Cloudflare Pages
3. Build command: `npm run build`
4. Output directory: `dist`
5. Node version: 18+

**Cost: $0/month** (Cloudflare free tier)
